Make a drawing of the active part following the `solidworks-api` skill sections 8.2 and 8.3. Extra wishes: $ARGUMENTS

1. Look at the part (`sw_status`, `sw_feature_tree`, an isometric `sw_screenshot`) and list the features that need dimensions, tolerances and GD&T.
2. Plan the sheet layout first: zones, view scales, ISO 129 spacing, the GD&T checklist. Show me the plan before creating the drawing.
3. Dry-run: resolve every edge you will dimension and report any that are missing.
4. Build the drawing in a new document, save it as PDF too, and run the collision check on the PDF.
5. Report the files, the checks and the open items.
